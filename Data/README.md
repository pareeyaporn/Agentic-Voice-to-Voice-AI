# Data

Raw data downloaded from Kaggle for the Agentic Voice-to-Voice AI project.

## Source

- **Dataset:** [Amazon Product Dataset 2020](https://www.kaggle.com/datasets/promptcloud/amazon-product-dataset-2020) — Kaggle, `promptcloud/amazon-product-dataset-2020`
- **License:** CC0 Public Domain
- **Downloaded:** 2026-08-15

## How it was downloaded

```python
import kagglehub

# Download latest version
path = kagglehub.dataset_download("promptcloud/amazon-product-dataset-2020")

print("Path to dataset files:", path)
```

Requires `pip install kagglehub`. No Kaggle API credentials were needed — this is a public dataset and downloaded anonymously.

## Known gaps (verified by running [Code/data/explore_data.ipynb](../Code/data/explore_data.ipynb) against the full CSV, not just a manual scan)

- **13 of 28 columns are entirely empty (100% null), across all 10,002 rows:** `Product Description, Stock, Size Quantity Variant, Product Details, Dimensions, Color, Quantity, Ingredients, Asin, Brand Name, Direction To Use, List Price, Sku`. Don't build filters or citations that assume any of these are populated.
- **`Asin` and `Sku` are both empty**, so there's no reliable external key to join a second dataset on — any join (e.g. for ratings) has to be fuzzy, by title, not authoritative.
- **No rating/stars column exists anywhere in this file**, and there is no review-level data (no reviews table).
- **`Category` is 91.7% populated** (830 rows blank) and **`Selling Price` is 98.9% non-null but only 95.2% parses to a clean number** — expect some cleanup in preprocessing.
- **`Product Name` has 137 duplicate values** — dedupe pass needed.
- **Category is heavily skewed:** ~67% `Toys & Games`; `Home & Kitchen` (~710 rows) and `Sports & Outdoors` (540 rows) are the next largest slices. `Household`/`Cleaning` categories total only ~25 rows combined — too sparse to use as the demo category.
